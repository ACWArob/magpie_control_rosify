ROS 2 Humble · UR5 CB3 + MAGPIE

From one script to a robot bus

The control stack used to be a single Python program driving every piece of hardware by hand. This PR breaks it into independent ROS 2 nodes that talk over named topics, services, and actions — so any part can be swapped, watched, or driven on its own.

01

What changed

Same hardware, same motion primitives. What moved is the boundary: from one process that imports every driver, to processes that publish and subscribe.

Before — one monolith
one control script
rtde_control → UR5
Dynamixel SDK → gripper
pyrealsense2 → camera
UDP socket → F/T

One process holds every driver. No introspection, nothing to subscribe to, and one crash takes the whole stack down. Hard to extend or plug into RViz / MoveIt / a learned policy.

Each node owns one device and exposes a named contract. Watch any stream with ros2 topic echo, restart one node without the others, and let downstream policies subscribe without touching drivers.

02

What each file brings to the table

Four hardware nodes each wrap one existing driver class as a thin ROS shell. One orchestrator node fuses them into a grasp. The rest is the contract and the wiring.

gripper_node.pyhardware node

Wraps the Gripper class (AX-12 servos over serial). Also fixes three real bugs found in review: an executor deadlock, an uncalibrated force→torque scaling, and blocking I/O in an async action.

Pub/gripper/state @10 Hz
Srvopen · close · set_position · set_force · calibrate · clear_error
Act/gripper/deligrasp (force-controlled close)
ur5_node.pyhardware node

Wraps UR5_Interface over RTDE — no teach-pendant URCap needed. Converts UR axis-angle ↔ ROS quaternion on every message. Adds teach mode and high-rate servo streaming.

Pub/arm/joint_states · /arm/tcp_pose @500 Hz
Srvmove_j · move_l · get_pose · set_speed · move_safe · stop · teach_mode
Sub/arm/servo_j_cmd · /arm/servo_l_cmd
ft_sensor_node.pyhardware node

Wraps the ATI Mini45 NetFT driver (a standalone sensor, not the wrist F/T). Streams the 6-axis wrench and can re-zero on command.

Pub/ft_sensor/wrench @50 Hz
Srv/ft_sensor/zero
tactile_sensor_node.pystub

Placeholder ROS shell for the E-flesh tactile fingers. Disabled by default — kept so the launch graph and future driver have a home.

Statedisabled (enable: false)
deligrasp_node.pyorchestrator

The brain. Subscribes to camera + arm pose, detects the target (Grounding DINO or OWL-ViT, optional LLM query), back-projects depth to a world point, then calls the arm and gripper to run the grasp. Uses a reentrant callback group so it can call services from inside its own callback.

Sub/camera/gripper_camera/* · /arm/tcp_pose
Calls/arm/move_l · /gripper/open · /gripper/deligrasp
Srv/grasp/execute (one-shot trigger)
magpie_msgscontract

Separate package of custom .msg / .srv / .action definitions (GripperState, MoveLinear, DeliGrasp…). Must build first — it's the shared language every node speaks.

Givestyped topics, services & actions
config/gripper_config.yamlconfig

One file holding every node's parameters — IPs, ports, publish rates, detector choice, grasp forces. Change behaviour without touching code.

Setsrobot_ip · publish_rate · detector_type · initial_force …
launch/…launch.pywiring

Brings up all five nodes with the config applied, in one command. Camera launches alongside on the gripper_camera namespace.

Runros2 launch magpie_control gripper_control.launch.py

03

One grasp, end to end

A single /grasp/execute call runs this whole chain. Every arrow between steps is a real ROS topic, service, or action — nothing is hidden inside one process anymore.

1
Trigger

A one-shot request kicks off the pipeline in the orchestrator.

/grasp/execute
2
Detect the object

Run the text-prompted detector on the latest color frame; take the highest-confidence box. Query can come straight from a natural-language instruction via LLM.

/camera/gripper_camera/color/image_raw
3
Localise in 3D

Sample depth at the box centroid, back-project through the camera intrinsics to a camera-frame point, then transform to the robot world frame using the live TCP pose × the fixed camera mount.

/camera/gripper_camera/depth/arm/tcp_pose
4
Open & approach

Open the gripper, then move linearly to a pose above the object, keeping the current tool orientation.

/gripper/open/arm/move_l
5
Descend to grasp

Drop slowly to just above the object centre — deliberately gentle for safety.

/arm/move_l  @0.05 m/s
6
DeliGrasp close

Force-controlled close for unknown-stiffness objects: squeeze, check for slip, tighten a little, repeat until held. Feedback and the force log come from /gripper/state — one source of truth.

/gripper/deligrasp [action]
7
Retreat

Lift straight back up by the approach height. On any failure along the way: open the gripper and return to the safe pose.

/arm/move_l/arm/move_safe  (on abort)
